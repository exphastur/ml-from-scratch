# ML From Scratch

从零手写机器学习算法，深入理解底层原理。

## 项目列表

### 1. Logistic Regression（逻辑回归）
- **路径**：`logistic_regression/`
- **时间**：2026-07-13
- **实现**：纯 numpy 手写，不调 sklearn 训练 API
- **核心**：梯度下降 + 交叉熵损失 + Sigmoid 激活
- **数据集**：鸢尾花（Iris）二分类
- **结果**：训练集 100%、测试集 100%
- **核心收获**：
  - 串起完整训练循环：前向传播 → 损失计算 → 梯度计算 → 参数更新
  - 矩阵乘法维度分析：`X.T @ error` 其中 X.T=(4,80)、error=(80,) → 结果=(4,)，一次算出 4 个梯度
  - 交叉熵损失实现：`-Σ[y*log(p) + (1-y)*log(1-p)] / n`
  - 梯度公式：`grad_w = X.T @ error / n`、`grad_b = np.sum(error) / n`

### 2. K-means Clustering（K-means 聚类）
- **路径**：`kmeans/`
- **时间**：2026-08-10
- **实现**：sklearn API 实操
- **核心**：无监督聚类，迭代更新中心点
- **数据集**：鸢尾花（Iris）3 类聚类
- **核心收获**：
  - K-means 完整算法：随机初始化 K 个中心 → 每个点归入最近中心（欧几里得距离）→ 重新取均值更新中心 → 重复直到收敛
  - 肘部法则（Elbow Method）：K vs WCSS 曲线找拐点，边际收益递减，本实验拐点在 K=3
  - **监督 vs 无监督本质区别**：聚类无语义需人工解读（簇 0/1/2 不知道是什么）vs 分类有语义直接可用（肺炎/感冒/健康）
  - **半监督学习工业思路**：无监督聚类 → 少量标注 → 监督学习，降低 90%+ 标注成本
  - K-means 两大问题：①随机初始化易陷局部最优（K-means++ 初始化 + n_init 多次运行解决）②K 值选择（肘部法则找拐点或业务需求直接指定）
  - API 区分：`cluster_centers_`（中心点坐标，用于画图/分析簇特征）vs `inertia_`（WCSS 数值，用于肘部曲线）

### 3. PCA（主成分分析）
- **路径**：`pca/`
- **时间**：2026-08-10
- **实现**：sklearn API 实操
- **核心**：无监督降维，找变化最大的方向
- **数据集**：鸢尾花（Iris）4 维 → 2 维
- **核心收获**：
  - **PCA 核心思想**：把 N 个特征重新组合成 M 个新特征（M < N），新特征 = 原始特征的线性组合，按"方差大小"排序
  - **主成分含义**：主成分1 = w1×特征1 + w2×特征2 + ...，权重决定含义。Iris 数据集中，主成分1 ≈ "花瓣大小"（权重 0.857），主成分2 ≈ "萼片 vs 花瓣比例"
  - **为什么用方差**：方差大 = 数据散得开 = 能更好地区分样本 = 信息多。PCA 通过"最大化方差"来"最小化信息损失"
  - **主成分垂直（独立）**：主成分1 和主成分2 相互垂直 = 不相关 = 不重复 = 提供新的信息维度
  - **降维效果**：4 维 → 2 维，保留 97.77% 方差（主成分1: 92.46%，主成分2: 5.31%）
  - **分类准确率对比**：原始 4 维准确率 100%，PCA 2 维准确率 100%，**差异 0%** —— 说明 PCA 成功保留了分类所需的关键信息
  - **核心结论**：如果原始特征高度相关（冗余），少量主成分就能保留大部分信息。不要简单认为"N 个特征就需要 N 个维度"
  - **应用价值**：①降维可视化（4 维 → 2 维可画图）②去冗余（自动消除特征间冗余）③防止过拟合（特征少了，模型更简单）
