## 项目列表

### 1. Logistic Regression（逻辑回归）
- **路径**：`logistic_regression/`
- **时间**：2026-07-13
- **实现**：纯 numpy 手写，不调 sklearn 训练 API
- **核心**：梯度下降 + 交叉熵损失 + Sigmoid 激活
- **数据集**：鸢尾花（Iris）二分类
- **结果**：训练集 100%、测试集 100%
- **核心收获**：
  - 串起完整训练循环：前向传播 → 损失计算 → 梯度计算 → 参数更新
  - 矩阵乘法维度分析：`X.T @ error` 其中 X.T=(4,80)、error=(80,) → 结果=(4,)，一次算出 4 个梯度
  - 交叉熵损失实现：`-Σ[y*log(p) + (1-y)*log(1-p)] / n`
  - 梯度公式：`grad_w = X.T @ error / n`、`grad_b = np.sum(error) / n`

### 2. K-means Clustering（K-means 聚类）
- **路径**：`kmeans/`
- **时间**：2026-08-10
- **实现**：sklearn API 实操
- **核心**：无监督聚类，迭代更新中心点
- **数据集**：鸢尾花（Iris）3 类聚类
- **核心收获**：
  - K-means 完整算法：随机初始化 K 个中心 → 每个点归入最近中心（欧几里得距离）→ 重新取均值更新中心 → 重复直到收敛
  - 肘部法则（Elbow Method）：K vs WCSS 曲线找拐点，边际收益递减，本实验拐点在 K=3
  - **监督 vs 无监督本质区别**：聚类无语义需人工解读（簇 0/1/2 不知道是什么）vs 分类有语义直接可用（肺炎/感冒/健康）
  - **半监督学习工业思路**：无监督聚类 → 少量标注 → 监督学习，降低 90%+ 标注成本
  - K-means 两大问题：①随机初始化易陷局部最优（K-means++ 初始化 + n_init 多次运行解决）②K 值选择（肘部法则找拐点或业务需求直接指定）
  - API 区分：`cluster_centers_`（中心点坐标，用于画图/分析簇特征）vs `inertia_`（WCSS 数值，用于肘部曲线）

### 3. PCA（主成分分析）
- **路径**：`pca/`
- **时间**：2026-08-10
- **实现**：sklearn API 实操
- **核心**：无监督降维，找变化最大的方向
- **数据集**：鸢尾花（Iris）4 维 → 2 维
- **核心收获**：
  - **PCA 核心思想**：把 N 个特征重新组合成 M 个新特征（M < N），新特征 = 原始特征的线性组合，按"方差大小"排序
  - **主成分含义**：主成分1 = w1×特征1 + w2×特征2 + ...，权重决定含义。Iris 数据集中，主成分1 ≈ "花瓣大小"（权重 0.857），主成分2 ≈ "萼片 vs 花瓣比例"
  - **为什么用方差**：方差大 = 数据散得开 = 能更好地区分样本 = 信息多。PCA 通过"最大化方差"来"最小化信息损失"
  - **主成分垂直（独立）**：主成分1 和主成分2 相互垂直 = 不相关 = 不重复 = 提供新的信息维度
  - **降维效果**：4 维 → 2 维，保留 97.77% 方差（主成分1: 92.46%，主成分2: 5.31%）
  - **分类准确率对比**：原始 4 维准确率 100%，PCA 2 维准确率 100%，**差异 0%** —— 说明 PCA 成功保留了分类所需的关键信息
  - **核心结论**：如果原始特征高度相关（冗余），少量主成分就能保留大部分信息。不要简单认为"N 个特征就需要 N 个维度"
  - **应用价值**：①降维可视化（4 维 → 2 维可画图）②去冗余（自动消除特征间冗余）③防止过拟合（特征少了，模型更简单）

### 4. 朴素贝叶斯 & SVM（核函数魔法）
- **路径**：`naive_bayes_svm/`
- **时间**：2026-08-12
- **实现**：sklearn API 实操
- **核心**：生成式分类（朴素贝叶斯）vs 判别式分类（SVM），核函数处理非线性数据
- **数据集**：垃圾短信分类（朴素贝叶斯）、Iris 和同心圆（SVM）
- **核心收获**：
  - **朴素贝叶斯的"朴素"假设**：各特征条件独立，P(A,B|类别) ≈ P(A|类别) × P(B|类别)，把组合爆炸（1.66 亿种）降到线性计算（1000 个词）
  - **为何需要朴素假设**：真实统计"免费+优惠+中奖"同时出现需要天文数字数据，朴素假设用连乘代替组合统计 → 能算，效果出奇地好
  - **生成式 vs 判别式**：朴素贝叶斯学 P(特征|类别)，逻辑回归学 P(类别|特征)；小样本时朴素贝叶斯更稳定（只需统计词频），大样本时判别式模型更强
  - **SVM 核函数魔法**：线性 SVM 只能画直线，同心圆数据准确率 42%（分不开）；核函数 SVM（RBF）把数据映射到高维空间，准确率 100%（完美分开）
  - **核技巧（Kernel Trick）**：不显式映射到高维，直接用核函数 K(x,y) = exp(-γ||x-y||²) 计算高维内积 → 计算量从指数爆炸降到 O(1)
  - **只改一个参数**：`kernel='linear'` vs `kernel='rbf'`，从"完全分不开"变成"完美分开"，这是 sklearn 设计哲学的体现

### 5. 特征工程基础
- **路径**：`feature_engineering/`
- **时间**：2026-08-14
- **实现**：纯手写实现 One-Hot 编码 + 离群值截断 + Min-Max 归一化
- **核心**：把原始数据转换成模型能用的格式（类别变量 → 数字，数值变量 → 统一尺度）
- **场景**：招聘系统预测候选人是否录用
- **核心收获**：
  - **One-Hot 编码避免"拍脑袋定权重"**：学历编码成1,2,3会让模型误以为"博士=3倍本科"；One-Hot 让模型从数据中学出每个学历的真实价值
  - **归一化消除尺度差异**：工资=25000、年龄=28，工资数值大会主导计算；归一化到 [0,1] 让所有特征"公平竞争"
  - **离群值处理防止污染**：期望工资 100万会把其他人压到接近 0；用"均值±3σ"截断离群值
  - **特征工程是迭代过程**：设计特征 → 训练模型 → 发现问题（如某特征被淹没）→ 改进特征，不是一次搞定
  - **实战价值**：真实 Kaggle 比赛中，特征工程往往比模型选择更重要 — 好特征+简单模型 > 差特征+复杂模型
  - **最终特征向量**：`[是否博士, 是否本科, 是否硕士, 年龄(归一化), 经验(归一化), 期望工资(归一化)]` 可直接喂给模型
