# 朴素贝叶斯 & SVM 实验

**日期：** 2026-08-12

**学习目标：** 理解生成式分类（朴素贝叶斯）vs 判别式分类（SVM），掌握核函数处理非线性数据的原理

## 实验1：朴素贝叶斯 vs 逻辑回归 vs 决策树

**数据集：** 简化的垃圾短信分类（800 条训练，200 条测试）

### 完整数据集结果（640 条训练）
- 朴素贝叶斯：100%
- 逻辑回归：100%
- 决策树：100%

### 小样本结果（50 条训练）
- 朴素贝叶斯：100%
- 逻辑回归：100%
- 决策树：100%

**结论：** 数据过于简单（8 条消息重复 100 次），无法体现模型差异。在真实复杂数据上，朴素贝叶斯在小样本时更稳定（因为只需统计词频），逻辑回归/决策树在大样本时更强。

## 实验2：SVM 核函数魔法

### 实验2.1：线性可分数据（Iris 前两类）
- 线性 SVM（kernel='linear'）：100%
- 核函数 SVM（kernel='rbf'）：100%
- **结论：** 线性数据上，两者都能完美分开

### 实验2.2：非线性可分数据（同心圆）
- 线性 SVM（kernel='linear'）：**42.22%** ❌ 分不开！
- 核函数 SVM（kernel='rbf'）：**100%** ✅ 完美分开！
- **结论：** 非线性数据上，必须用核函数才能分开

## 核心洞察

### 朴素贝叶斯的"朴素"

**问题：** 特征组合爆炸
- 1000 个词的词汇表，任意 3 个词的组合 ≈ 1.66 亿种
- 训练数据只有几千条，绝大多数组合没出现过

**朴素假设：** 各特征条件独立
```
P(免费,优惠,中奖 | 垃圾) ≈ P(免费|垃圾) × P(优惠|垃圾) × P(中奖|垃圾)
```

**权衡：**
- ✅ 计算量从 O(2^N) 降到 O(N)
- ✅ 小样本场景依然能工作
- ❌ 忽略了特征间的相关性（"免费"和"中奖"经常一起出现）

**适用场景：** 数据少、特征多、特征相关性不强（文本分类、垃圾邮件过滤）

---

### SVM 核函数的魔法

**线性 SVM：** 只能画直线/超平面分类
- 同心圆数据（内圈一类、外圈一类）：直线无法分开 → 准确率 42%

**核函数 SVM（RBF）：** 把数据映射到高维空间
- 核技巧：不显式映射，直接用核函数 `K(x,y) = exp(-γ||x-y||²)` 计算高维内积
- 在高维空间用超平面分开，投影回原空间就是曲线
- 同心圆数据：完美分开 → 准确率 100%

**关键：** 只改一个参数 `kernel='rbf'`，就从"完全分不开"变成"完美分开"

## 生成式 vs 判别式

| 维度 | 朴素贝叶斯（生成式） | 逻辑回归/SVM（判别式） |
|------|---------------------|---------------------|
| 学什么 | P(特征\|类别) + P(类别) | P(类别\|特征) |
| 小样本 | 稳定（只需统计词频） | 不稳定（边界学不出） |
| 大样本 | 天花板低（假设太强） | 准确率更高 |
| 速度 | 快（只需统计） | 慢（需要优化） |
