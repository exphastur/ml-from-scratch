# K-means 聚类实战

**阶段 2.5 第三课** —— 无监督学习入门

---

## 📋 实验内容

1. **K-means 聚类**：用 sklearn 对 150 个样本做聚类（K=3）
2. **肘部法则**：用 K=1~10 各训练一次，画 WCSS 曲线找最优 K

---

## 🎯 核心收获

### 1. K-means 迭代机制（自己推导）
```
① 随机选 K 个初始中心
② 每个点归入最近的中心
③ 重新计算每组的均值（新中心）
④ 重复 ②-③ 直到中心不再移动（收敛）
```

### 2. 肘部法则找最优 K
- 横轴 K，纵轴 WCSS（组内距离平方和）
- 找"拐点"（边际收益递减的位置）
- 本实验：拐点在 K=3，与真实数据一致

### 3. 监督 vs 无监督的本质区别
- **无监督学习**：发现数据的自然分组（聚类），但**无业务语义**，需人工解读
- **监督学习**：预测有明确业务含义的标签，**直接对齐业务目标**
- **半监督学习**：无监督聚类 → 少量标注 → 监督学习（工业界降低标注成本的标准做法）

### 4. K-means 的两个关键问题
- **问题1：随机初始化易陷入局部最优**
  - 解法：K-means++（初始中心尽量分散）+ 多次运行取最好结果（`n_init=10`）
- **问题2：K 怎么选？**
  - 解法：肘部法则（找 WCSS 曲线的拐点）或业务需求

---

## 📊 实验结果

### 聚类效果（K=3）
- 训练数据：150 个样本，2 个特征（身高、体重类比）
- 结果：3 个簇清晰分离，中心点位置合理
- 可视化：`kmeans_result.png`

### 肘部法则
- K=1→2：WCSS 下降明显
- K=2→3：WCSS 继续下降
- K=3→4：下降变缓（**拐点**）
- K>4：边际收益递减
- 可视化：`elbow.png`

## 🔧 关键 API

```python
from sklearn.cluster import KMeans

# 创建 K-means 对象
km = KMeans(n_clusters=3, n_init=10, random_state=42)

# 训练 + 预测
labels = km.fit_predict(X)  # 返回每个点的簇标签（0/1/2）

# 获取中心点坐标
centers = km.cluster_centers_  # shape: (K, n_features)

# 获取 WCSS（组内距离平方和）
wcss = km.inertia_  # 一个标量，越小越好
```

## 💡 核心洞察

1. **K-means 和梯度下降是同一范式**：随机初始化 → 反复迭代 → 收敛
2. **无监督学习的价值**：降低标注成本的前置步骤（半监督学习）
3. **K-means 的目标函数**：最小化 WCSS（就像梯度下降最小化损失函数）
4. **工业界应用**：客户分群、图像压缩、异常检测、推荐系统召回
