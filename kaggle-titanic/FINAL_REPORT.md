## 一、项目概述

### 背景
1912年泰坦尼克号沉船，本项目使用 891 名乘客的数据训练模型，预测另外 418 名乘客的生还情况。

### 数据集
- **训练集：** 891 条样本，12 个特征
- **测试集：** 418 条样本（Kaggle 提交）
- **核心特征：** Pclass（船舱等级）、Sex（性别）、Age（年龄）、SibSp/Parch（家庭成员）、Fare（票价）、Cabin（船舱号）、Embarked（登船港口）

---

## 二、数据探索（EDA）核心发现

### 1. 生存率总体分布
- 整体生存率：38.4%（342人生还 / 549人遇难）

### 2. 关键影响因素

**性别影响巨大（"女士优先"规则）**
- 女性生存率：74%
- 男性生存率：19%

**船舱等级显著（社会地位 → 逃生机会）**
- 头等舱：63%
- 二等舱：47%
- 三等舱：24%

**家庭规模的倒U型曲线（重要发现）**
- 独自1人：30%
- 小家庭2-4人：50-70%（黄金规模，机动灵活 + 互相照应）
- 大家庭5+人：20%以下（决策慢、逃生难）

### 3. 缺失值分析
- Cabin：77% 缺失
- Age：20% 缺失
- Embarked：2 条缺失

---

## 三、特征工程

### 创建的新特征

1. **FamilySize = SibSp + Parch + 1**
   - 家庭总人数（包括自己）

2. **FamilyCategory（三分类）**
   - Alone（1人）
   - Small（2-4人）
   - Large（5+人）
   - **设计原因：** 基于倒U型曲线发现，三分类保留了"小家庭优势"和"大家庭劣势"的细节

3. **CabinDeck（船舱甲板层）**
   - 从 Cabin 列提取首字母（A/B/C/D/E/F/G/T）
   - 缺失值标记为 'Unknown'

### 缺失值处理

1. **Age 分组填充**
   - 按 Pclass + Sex 分组，用各组中位数填充
   - **原因：** 头等舱 vs 三等舱年龄分布有差异（社会阶层 → 年龄差异）

2. **Embarked 众数填充**
   - 填充为 'S'（最常见的登船港口）

3. **Fare 中位数填充**
   - test.csv 中有 1 条 Fare 缺失

### One-Hot 编码
- Sex（性别）
- Embarked（登船港口）
- FamilyCategory（家庭类别）
- CabinDeck（船舱甲板）

**最终特征数：** 19 列（原始 6 列 + One-Hot 编码生成 13 列）

## 四、模型对比实验

### Baseline 模型对比（交叉验证）

| 模型 | 训练准确率 | 测试准确率 | 过拟合程度 | 训练时间(s) |
|------|----------|----------|----------|----------|
| 逻辑回归 | 81.01% | 83.24% | -2.23% | 0.0062 |
| 随机森林 | 97.19% | 82.12% | +15.07% | 0.0624 |
| XGBoost | 82.30% | 80.45% | +1.85% | 0.0499 |

**初步结论：**
- 逻辑回归表现最好（83.24%），且几乎无过拟合
- 随机森林严重过拟合（+15.07%）
- XGBoost 未调优表现最差

---

## 五、XGBoost 超参数调优

### 调优策略：逐步调优
1. 先调 `n_estimators`（树的数量）
2. 再调 `max_depth`（树的深度）
3. 最后调 `scale_pos_weight`（类别权重）

### 调优结果

#### 第1轮：n_estimators
| 参数值 | 准确率 |
|--------|--------|
| 50 | **83.80%** ✅ |
| 100 | 83.24% |
| 150 | 82.68% |
| 200 | 82.68% |
| 300 | 82.68% |

**结论：** 50棵树最优，更多的树导致过拟合

#### 第2轮：max_depth
| 参数值 | 准确率 |
|--------|--------|
| 3 | **83.80%** ✅ |
| 4 | 83.24% |
| 5 | 82.12% |
| 6 | 81.56% |
| 7 | 81.56% |

**结论：** 浅树（depth=3）最优，深树记住噪音

#### 第3轮：scale_pos_weight
| 参数值 | 理论依据 | 准确率 |
|--------|---------|--------|
| 1.0 | 不调整 | **83.80%** ✅ |
| 1.66 | 类别比例 549/342 | 83.24% |
| 1.99 | 类别比例 62.4/37.6 | 82.68% |
| 1.33 | 适度调整 | 83.24% |

**结论：** 不调整权重反而最好，XGBoost 内部已对不平衡有鲁棒性

### 最终最佳参数
```python
n_estimators = 50
max_depth = 3
scale_pos_weight = 1.0
random_state = 42
```

**测试集准确率：** 83.80%（成功超越逻辑回归的 83.24%，提升 0.56 个百分点）

## 六、三大反直觉洞察 ⭐⭐⭐

### 洞察1："越复杂越好"是错的
- 50棵树 > 300棵树（更多的树 = 过拟合）
- depth=3 > depth=7（深树记住噪音，浅树学到规律）
- **奥卡姆剃刀原则验证：** 能用简单模型解决，别上复杂模型

### 洞察2：理论建议值 ≠ 实际最优值
- 类别分布：Died 62.4% vs Survived 37.6%
- 理论公式：`scale_pos_weight = 549/342 ≈ 1.66`
- 实验结果：`weight=1.0`（不调整）反而最优
- **原因：** XGBoost 内部已对类别不平衡有鲁棒性，强行加权 = 过度补偿

### 洞察3：调参顺序的重要性
- 先调影响最大的（n_estimators）
- 再调次要的（max_depth）
- 最后微调（scale_pos_weight）
- **好处：** 能看清每个参数的独立影响，避免参数间交互混淆

## 九、可改进方向

1. **特征工程深度不够**
   - 可以尝试：Name 中的称谓（Mr./Mrs./Master）、Ticket 编号模式
   - 特征交叉：Pclass × Sex、Age × Pclass

2. **模型集成**
   - 逻辑回归 + XGBoost + 随机森林 投票集成
   - Stacking：用多个模型的预测作为新特征

3. **超参数调优不够深**
   - 只调了 3 个参数，XGBoost 还有 `learning_rate`、`subsample`、`colsample_bytree` 等
   - 可以用网格搜索（GridSearchCV）或贝叶斯优化

4. **交叉验证不够充分**
   - 只用了简单的 train_test_split
   - 应该用 K 折交叉验证（K=5 或 10）评估模型稳定性
