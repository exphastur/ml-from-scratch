# 特征工程基础实验

**日期**：2026-08-14  
**目标**：理解并实现特征工程的核心技巧：类别变量编码、数值变量归一化、离群值处理

---

## 实验场景

模拟招聘系统：预测候选人是否会被录用。原始数据包含：
- **类别变量**：学历（本科/硕士/博士）
- **数值变量**：年龄、工作年限、期望工资
- **离群值**：期望工资 100万（测试离群值处理）

---

## 核心技术

### 1. One-Hot 编码（类别变量 → 数字）

**问题**：学历是文字，模型只能处理数字。

**错误方案**：编码成 1, 2, 3 → 会让模型误以为"博士=3倍本科"

**正确方案**：One-Hot 编码
```
本科 → [0, 1, 0]
硕士 → [0, 0, 1]
博士 → [1, 0, 0]
```

**核心思想**：把一个"类别选择题"拆成多个"是/否判断题"，让模型自己学出每个类别的权重。

---

### 2. 离群值截断（防止极端值污染数据）

**问题**：有人期望工资写 100万，会把其他人都压到接近 0。

**方案**：用"均值 ± 3×标准差"定义合理范围，超出范围的用边界值替换。

**本实验结果**：
```
合理范围: [0, 1388241]
期望 100万 → 未被截断（因为数据量太少，标准差被拉得很大）
```

**启示**：统计方法在数据量少时会失效，真实项目需结合业务规则（如"期望工资 > 10万就截断"）。

---

### 3. Min-Max 归一化（消除尺度差异）

**问题**：工资=25000，年龄=28 → 工资的数值大，会主导模型计算。

**方案**：Min-Max 归一化，把所有特征压缩到 [0, 1]
```
归一化后 = (值 - 最小值) / (最大值 - 最小值)
```

**本实验结果**：
```
张三: 年龄=0.083, 经验=0.167, 期望工资=0.000
离群值: 年龄=1.0, 经验=1.0, 期望工资=1.0
```

---

## 最终特征向量

每个候选人被表示成一个 6 维向量：
```
[是否博士, 是否本科, 是否硕士, 年龄(归一化), 经验(归一化), 期望工资(归一化)]

张三: [0, 1, 0, 0.083, 0.167, 0.0]
李四: [0, 0, 1, 0.0, 0.056, 0.003]
王五: [1, 0, 0, 0.167, 0.0, 0.01]
```

这些向量可以直接喂给逻辑回归、神经网络等模型。

---

## 核心洞察

1. **One-Hot 避免了"拍脑袋定权重"** — 不是你定义博士=3、硕士=2，而是让模型从数据里学出每个学历的真实价值
2. **归一化让特征"公平竞争"** — 避免大数值特征（工资）淹没小数值特征（年龄）
3. **特征工程是迭代过程** — 设计特征 → 训练模型 → 发现问题 → 改进特征，不是一次搞定
4. **真实项目中，特征工程往往比模型选择更重要** — 好的特征+简单模型 > 差的特征+复杂模型
